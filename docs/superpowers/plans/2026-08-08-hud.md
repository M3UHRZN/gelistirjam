# HUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a four-corner HUD (crosshair, stamina, fuse counter, flashlight, interaction prompt) whose elements lag behind camera rotation with spring-damper inertia, while the crosshair stays pixel-locked to screen centre.

**Architecture:** A new `Game.UI` assembly holds one small MonoBehaviour per HUD element. Each widget polls its gameplay source in a single `Refresh()` method. A single `HudCameraMotion` measures camera angular velocity; `HudRootSway` and `HudSway` turn that into spring-driven offsets on top of each element's authored rest position. Dependency direction is one-way: `Game.UI` → `Game.Gameplay`, never the reverse.

**Tech Stack:** Unity 6000.3.13f1 (URP), legacy `UnityEngine.UI` (`Text`, `Image`, `CanvasGroup`), Unity assembly definitions, Unity Editor menu tooling for scene construction.

**Spec:** `docs/superpowers/specs/2026-08-08-hud-design.md`

## Global Constraints

- **No PlayMode or EditMode tests are to be written.** This is an explicit, repeated instruction from the project owner ("play mode test yapma bana söyle yaparim"). Every task is verified by a clean Unity compile plus, at the end, a manual play checklist the owner runs. Spec section 7.2 states the one testable pure function (`HudSpring.Step`) is deliberately left untested.
- Target Unity version: **6000.3.13f1**. URP.
- New assembly `Game.UI` references exactly: `Game.Core`, `Game.Gameplay`, `UnityEngine.UI`. **`Game.Gameplay` must never reference `Game.UI`.**
- Namespace for all new runtime files: `Game.UI`. Namespace for the editor builder: `Game.Editor`.
- Text rendering uses legacy `UnityEngine.UI.Text`. **Do not add TextMeshPro** — it is not referenced anywhere in this project and the jam has no budget for a new dependency.
- No external sprite assets. Bars and frames are plain `Image` with no sprite; the flashlight indicator is the `(F)` glyph, and all text uses `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")`.
- The crosshair lives under `FixedRoot` and **never** gets a `HudSway`/`HudRootSway` component. Rationale (spec 2.1): `PlayerGazeDetector` and `PlayerInteraction` both raycast from exact screen centre, and TGD §19-21 makes eye contact a core mechanic that permanently raises Anger — a drifting crosshair would lie to the player.
- Sway is always **additive** on top of the `anchoredPosition` captured in `Awake`. Never write the swayed value back as the rest pose.
- All event subscriptions live in matched `OnEnable`/`OnDisable` pairs. This project has already shipped a silent-event-lifetime bug; the entire class comment on `SceneWiring` is about it.
- Default sway direction: every widget multiplier shares the same sign, differing only in **magnitude** (parallax). The fan-out at the corners comes from `HudRootSway`'s Z rotation, not from per-corner sign flips.
- Every widget with a missing source reference logs **one** `Debug.LogWarning` in `Awake` and sets `enabled = false`. The HUD is a view; a missing reference must never throw per-frame or break gameplay.
- Unity compile status is checked with `mcp__unityMCP__read_console` after `mcp__unityMCP__refresh_unity`. "Clean" means zero compile errors.

- [ ] **Step 2: Create `HudSpring.cs`**

```csharp
using UnityEngine;

namespace Game.UI
{
    /// <summary>
    /// The one spring-damper integrator behind every HUD motion component. Kept static and
    /// MonoBehaviour-free so HudSway and HudRootSway share a single implementation instead of each
    /// growing its own copy that drifts out of sync during tuning.
    /// </summary>
    public static class HudSpring
    {
        /// <summary>
        /// Largest timestep the integrator will take. Semi-implicit Euler diverges on a big dt: a
        /// hitch frame (asset load, NavMesh bake) with a raw deltaTime of ~0.4s is enough to fling
        /// the HUD off screen and never bring it back. Clamping trades a moment of slow-motion sway
        /// for never exploding.
        /// </summary>
        public const float MaxTimeStep = 1f / 30f;

        public static void Step(ref Vector2 offset, ref Vector2 velocity, Vector2 target,
            float stiffness, float damping, float deltaTime)
        {
            float dt = Mathf.Min(deltaTime, MaxTimeStep);
            Vector2 acceleration = (target - offset) * stiffness - velocity * damping;
            velocity += acceleration * dt;
            offset += velocity * dt;
        }

        public static void Step(ref float offset, ref float velocity, float target,
            float stiffness, float damping, float deltaTime)
        {
            float dt = Mathf.Min(deltaTime, MaxTimeStep);
            float acceleration = (target - offset) * stiffness - velocity * damping;
            velocity += acceleration * dt;
            offset += velocity * dt;
        }
    }
}
```

- [ ] **Step 3: Create `HudCameraMotion.cs`**

```csharp
using UnityEngine;

namespace Game.UI
{
    /// <summary>
    /// The single measurement source every HUD sway component reads: how fast the view is rotating,
    /// in degrees per second.
    ///
    /// Measures the assigned camera Transform's rotation rather than asking PlayerController. Two
    /// reasons: whatever drives the camera (player input today, a scripted sequence later) then
    /// makes no difference, and PlayerController does not expose pitch at all — only Yaw — so a
    /// controller-based reading could never produce the vertical component.
    ///
    /// Runs in LateUpdate because PlayerController.HandleLook() rotates the camera in Update.
    /// Measuring in Update would read the previous frame's rotation and leave the HUD one frame
    /// behind the very motion it exists to trail deliberately. DefaultExecutionOrder(-100) puts this
    /// ahead of the sway components' own LateUpdate so they consume this frame's value, not last
    /// frame's.
    /// </summary>
    [DisallowMultipleComponent]
    [DefaultExecutionOrder(-100)]
    public class HudCameraMotion : MonoBehaviour
    {
        [SerializeField, Tooltip("Camera transform whose rotation drives HUD inertia. In MainGame this is Player/CameraPivot/PlayerCamera.")]
        private Transform cameraTransform;

        [SerializeField, Tooltip("Per-second exponential smoothing rate. Higher tracks the camera more tightly; lower is smoother and laggier.")]
        private float smoothing = 18f;

        [SerializeField, Tooltip("Degrees/second the measurement is clamped to. Flicking faster than this no longer increases HUD displacement.")]
        private float maxTrackedRate = 400f;

        [SerializeField, Tooltip("A single frame rotating faster than this is a teleport or respawn, not a look input — the frame is discarded and motion resets.")]
        private float teleportThresholdDegrees = 1500f;

        /// <summary>x = yaw degrees/second, y = pitch degrees/second. Stays zero while no camera is assigned.</summary>
        public Vector2 AngularVelocity { get; private set; }

        private float previousYaw;
        private float previousPitch;
        private bool hasPrevious;

        public void Bind(Transform camera)
        {
            cameraTransform = camera;
            ResetMotion();
        }

        /// <summary>
        /// Drops the accumulated reading and the previous-frame baseline. Called internally by the
        /// teleport guard; public so an explicit scene or level transition can start the HUD at rest.
        /// </summary>
        public void ResetMotion()
        {
            AngularVelocity = Vector2.zero;
            hasPrevious = false;
        }

        private void OnEnable() => ResetMotion();

        private void LateUpdate()
        {
            if (cameraTransform == null)
            {
                AngularVelocity = Vector2.zero;
                return;
            }

            Vector3 euler = cameraTransform.eulerAngles;
            float yaw = euler.y;
            float pitch = euler.x;

            float dt = Time.deltaTime;
            if (!hasPrevious || dt <= 0f)
            {
                previousYaw = yaw;
                previousPitch = pitch;
                hasPrevious = true;
                return;
            }

            float yawRate = Mathf.DeltaAngle(previousYaw, yaw) / dt;
            float pitchRate = Mathf.DeltaAngle(previousPitch, pitch) / dt;

            previousYaw = yaw;
            previousPitch = pitch;

            if (Mathf.Abs(yawRate) > teleportThresholdDegrees || Mathf.Abs(pitchRate) > teleportThresholdDegrees)
            {
                ResetMotion();
                return;
            }

            Vector2 raw = new Vector2(
                Mathf.Clamp(yawRate, -maxTrackedRate, maxTrackedRate),
                Mathf.Clamp(pitchRate, -maxTrackedRate, maxTrackedRate));

            float t = 1f - Mathf.Exp(-smoothing * dt);
            AngularVelocity = Vector2.Lerp(AngularVelocity, raw, t);
        }
    }
}
```

```csharp
using UnityEngine;

namespace Game.UI
{
    /// <summary>
    /// Per-widget parallax layer. Trails the camera by a spring-damped pixel offset added on top of
    /// the position authored in the Inspector.
    ///
    /// Give every widget the same sign and different magnitudes and the HUD reads as one object with
    /// depth, all of it lagging the same way — the physically honest reading. Flip a sign to send one
    /// element against the grain; the fan-out at opposite corners is HudRootSway's job, not this
    /// component's.
    /// </summary>
    [DisallowMultipleComponent]
    [RequireComponent(typeof(RectTransform))]
    public class HudSway : MonoBehaviour
    {
        [SerializeField] private HudCameraMotion motion;

        [SerializeField, Tooltip("Signed pixels of lag per degree/second of camera rotation. X reacts to yaw, Y to pitch. Larger magnitude = nearer-feeling layer.")]
        private Vector2 pixelsPerDegreePerSecond = new Vector2(-0.06f, 0.04f);

        [SerializeField, Tooltip("Hard cap on displacement so a violent flick can never push the element off screen.")]
        private float maxOffsetPixels = 26f;

        [SerializeField] private float stiffness = 90f;
        [SerializeField] private float damping = 14f;

        private RectTransform rect;
        private Vector2 restPosition;
        private Vector2 offset;
        private Vector2 velocity;

        public void Bind(HudCameraMotion cameraMotion) => motion = cameraMotion;

        private void Awake()
        {
            rect = (RectTransform)transform;
            // The authored position is the rest pose and is never written back to. Everything below
            // is additive, so re-entering Play Mode always starts from the same layout.
            restPosition = rect.anchoredPosition;
        }

        private void LateUpdate()
        {
            if (motion == null) return;

            Vector2 target = Vector2.ClampMagnitude(
                Vector2.Scale(motion.AngularVelocity, pixelsPerDegreePerSecond), maxOffsetPixels);

            HudSpring.Step(ref offset, ref velocity, target, stiffness, damping, Time.deltaTime);
            rect.anchoredPosition = restPosition + offset;
        }
    }
}
```

- [ ] **Step 2: Create `HudRootSway.cs`**

```csharp
using UnityEngine;

namespace Game.UI
{
    /// <summary>
    /// The "glass plate" layer: translates and slightly rolls the whole HUD root. The roll is what
    /// makes opposite corners drift apart under a fast turn — angular inertia — without assigning
    /// each corner a fake direction of its own.
    ///
    /// Set maxRotationDegrees to 0 for a single rigid plate that only translates.
    /// </summary>
    [DisallowMultipleComponent]
    [RequireComponent(typeof(RectTransform))]
    public class HudRootSway : MonoBehaviour
    {
        [SerializeField] private HudCameraMotion motion;

        [SerializeField, Tooltip("Signed pixels of lag per degree/second of camera rotation. X reacts to yaw, Y to pitch.")]
        private Vector2 pixelsPerDegreePerSecond = new Vector2(-0.05f, 0.035f);

        [SerializeField] private float maxOffsetPixels = 18f;

        [SerializeField, Tooltip("Signed degrees of Z roll per degree/second of yaw. This is the fan-out control: raise it to spread the corners further apart, set 0 for pure translation.")]
        private float degreesPerDegreePerSecond = -0.012f;

        [SerializeField] private float maxRotationDegrees = 2.5f;

        [SerializeField] private float stiffness = 70f;
        [SerializeField] private float damping = 12f;

        private RectTransform rect;
        private Vector2 restPosition;
        private float restRotation;
        private Vector2 offset;
        private Vector2 velocity;
        private float rotationOffset;
        private float rotationVelocity;

        public void Bind(HudCameraMotion cameraMotion) => motion = cameraMotion;

        private void Awake()
        {
            rect = (RectTransform)transform;
            restPosition = rect.anchoredPosition;
            restRotation = rect.localEulerAngles.z;
        }

        private void LateUpdate()
        {
            if (motion == null) return;

            float dt = Time.deltaTime;

            Vector2 positionTarget = Vector2.ClampMagnitude(
                Vector2.Scale(motion.AngularVelocity, pixelsPerDegreePerSecond), maxOffsetPixels);
            HudSpring.Step(ref offset, ref velocity, positionTarget, stiffness, damping, dt);
            rect.anchoredPosition = restPosition + offset;

            float rotationTarget = Mathf.Clamp(
                motion.AngularVelocity.x * degreesPerDegreePerSecond,
                -maxRotationDegrees, maxRotationDegrees);
            HudSpring.Step(ref rotationOffset, ref rotationVelocity, rotationTarget, stiffness, damping, dt);
            rect.localRotation = Quaternion.Euler(0f, 0f, restRotation + rotationOffset);
        }
    }
}
```

```csharp
using UnityEngine;

namespace Game.UI
{
    /// <summary>
    /// The crosshair's share of the HUD's inertia — expressed entirely as spread and opacity, never
    /// as position. The centre of the screen is where PlayerGazeDetector and PlayerInteraction cast
    /// from, so a crosshair that moved would misreport where the player is actually aiming (spec
    /// section 2.1). Opening the ticks under fast rotation reads as the same "the HUD felt that"
    /// reaction without ever moving the aim point.
    /// </summary>
    [DisallowMultipleComponent]
    public class CrosshairPulse : MonoBehaviour
    {
        [SerializeField] private HudCameraMotion motion;

        [SerializeField, Tooltip("The four tick marks. Their authored distance from centre is captured as the resting spread.")]
        private RectTransform[] ticks = new RectTransform[4];

        [SerializeField] private CanvasGroup group;

        [SerializeField, Tooltip("Extra pixels the ticks push outward at full rotation speed.")]
        private float maxExtraSpread = 7f;

        [SerializeField, Tooltip("Rotation speed (degrees/second) treated as 'full' for spread and fade.")]
        private float fullSpreadRate = 260f;

        [SerializeField, Range(0f, 1f)] private float restAlpha = 0.85f;
        [SerializeField, Range(0f, 1f)] private float movingAlpha = 0.35f;

        [SerializeField] private float stiffness = 120f;
        [SerializeField] private float damping = 18f;

        private Vector2[] directions;
        private float[] restDistances;
        private float spread;
        private float spreadVelocity;

        public void Bind(HudCameraMotion cameraMotion) => motion = cameraMotion;

        private void Awake()
        {
            directions = new Vector2[ticks.Length];
            restDistances = new float[ticks.Length];
            for (int i = 0; i < ticks.Length; i++)
            {
                if (ticks[i] == null) continue;
                Vector2 authored = ticks[i].anchoredPosition;
                restDistances[i] = authored.magnitude;
                // A tick authored exactly at centre has no direction to push along; park it at
                // straight up rather than producing a NaN from normalizing a zero vector.
                directions[i] = authored.sqrMagnitude > 0.0001f ? authored.normalized : Vector2.up;
            }
        }

        private void LateUpdate()
        {
            if (motion == null) return;

            float rate = motion.AngularVelocity.magnitude;
            float normalized = fullSpreadRate > 0f ? Mathf.Clamp01(rate / fullSpreadRate) : 0f;

            HudSpring.Step(ref spread, ref spreadVelocity, normalized * maxExtraSpread,
                stiffness, damping, Time.deltaTime);

            for (int i = 0; i < ticks.Length; i++)
            {
                if (ticks[i] == null) continue;
                ticks[i].anchoredPosition = directions[i] * (restDistances[i] + spread);
            }

            if (group != null) group.alpha = Mathf.Lerp(restAlpha, movingAlpha, normalized);
        }
    }
}
```

```csharp
using Game.Gameplay.Interaction;
using UnityEngine;
using UnityEngine.UI;

namespace Game.UI
{
    /// <summary>
    /// Colours the crosshair when something interactable is under it. The interaction ray already
    /// originates from screen centre, so the crosshair is the honest place to report "this is
    /// usable" — cheaper to read than a separate icon and impossible to mis-associate with the wrong
    /// object.
    /// </summary>
    [DisallowMultipleComponent]
    public class CrosshairWidget : MonoBehaviour
    {
        [SerializeField] private PlayerInteraction interaction;

        [SerializeField, Tooltip("Every Graphic making up the crosshair: the four ticks and the centre dot.")]
        private Graphic[] parts;

        [SerializeField] private Color idleColor = new Color(1f, 1f, 1f, 1f);
        [SerializeField] private Color targetedColor = new Color(1f, 0.86f, 0.45f, 1f);

        private bool lastTargeted;

        public void Bind(PlayerInteraction playerInteraction) => interaction = playerInteraction;

        private void Awake()
        {
            if (interaction == null)
            {
                Debug.LogWarning($"[HUD] {name}: PlayerInteraction not assigned — crosshair target highlight disabled.", this);
                enabled = false;
                return;
            }

            lastTargeted = false;
            Apply(false);
        }

        private void Update() => Refresh();

        /// <summary>The single place this widget reads gameplay state (spec section 8).</summary>
        private void Refresh()
        {
            bool targeted = !string.IsNullOrEmpty(interaction.CurrentPrompt);
            if (targeted == lastTargeted) return;
            lastTargeted = targeted;
            Apply(targeted);
        }

        private void Apply(bool targeted)
        {
            Color color = targeted ? targetedColor : idleColor;
            for (int i = 0; i < parts.Length; i++)
            {
                if (parts[i] != null) parts[i].color = color;
            }
        }
    }
}
```

```csharp
using Game.Gameplay.Interaction;
using UnityEngine;
using UnityEngine.UI;

namespace Game.UI
{
    /// <summary>
    /// Draws PlayerInteraction.CurrentPrompt. Until this existed, FuseBox.InteractionPrompt ("Hold E
    /// to activate fuse") was computed every frame and never rendered anywhere — the player had no
    /// way at all to learn a fuse was interactable.
    /// </summary>
    [DisallowMultipleComponent]
    public class InteractionPromptWidget : MonoBehaviour
    {
        [SerializeField] private PlayerInteraction interaction;
        [SerializeField] private Text label;
        [SerializeField] private CanvasGroup group;
        [SerializeField] private float fadeSeconds = 0.12f;

        public void Bind(PlayerInteraction playerInteraction) => interaction = playerInteraction;

        private void Awake()
        {
            if (interaction == null || label == null || group == null)
            {
                Debug.LogWarning($"[HUD] {name}: interaction/label/group not fully assigned — interaction prompt disabled.", this);
                enabled = false;
                return;
            }

            group.alpha = 0f;
        }

        private void Update() => Refresh();
```

```csharp
using Game.Gameplay.Player;
using UnityEngine;
using UnityEngine.UI;

namespace Game.UI
{
    /// <summary>
    /// Stamina bar (TGD section 7). Always visible — the approved HUD is the classic persistent kind.
    ///
    /// The exhausted pulse is not decoration: PlayerController refuses to clear IsExhausted until the
    /// bar is back above 30%, so a player who has just emptied it and sees a partly-refilled bar
    /// would otherwise have no way to understand why sprint is still refusing to engage.
    /// </summary>
    [DisallowMultipleComponent]
    public class StaminaWidget : MonoBehaviour
    {
        [SerializeField] private PlayerController player;

        [SerializeField, Tooltip("Image with Type = Filled, Fill Method = Horizontal.")]
        private Image fill;

        [SerializeField] private CanvasGroup group;

        [SerializeField] private Color normalColor = new Color(0.85f, 0.85f, 0.82f, 0.9f);
        [SerializeField] private Color exhaustedColor = new Color(0.85f, 0.22f, 0.18f, 0.95f);

        [SerializeField, Tooltip("Pulses per second while exhausted.")]
        private float exhaustedPulseHz = 1f;

        [SerializeField, Range(0f, 1f), Tooltip("How deep the exhausted pulse dips in alpha.")]
        private float exhaustedPulseDepth = 0.45f;

        [SerializeField, Range(0f, 1f), Tooltip("Alpha while stamina is full and the player is idle. Left at 1: the approved HUD keeps the bar fully visible at all times. Lower it only if you decide to walk that back.")]
        private float idleAlpha = 1f;

        public void Bind(PlayerController playerController) => player = playerController;

        private void Awake()
        {
            if (player == null || fill == null)
            {
                Debug.LogWarning($"[HUD] {name}: player/fill not assigned — stamina bar disabled.", this);
                enabled = false;
            }
        }

        private void Update() => Refresh();

        /// <summary>The single place this widget reads gameplay state (spec section 8).</summary>
        private void Refresh()
        {
            float max = player.MaxStamina;
            fill.fillAmount = max > 0f ? Mathf.Clamp01(player.CurrentStamina / max) : 0f;

            if (player.IsExhausted)
            {
                float pulse = 0.5f + 0.5f * Mathf.Sin(Time.time * exhaustedPulseHz * Mathf.PI * 2f);
                Color color = exhaustedColor;
                color.a *= Mathf.Lerp(1f - exhaustedPulseDepth, 1f, pulse);
                fill.color = color;
            }
            else
            {
                fill.color = normalColor;
            }

            if (group != null)
            {
                bool idle = !player.IsSprinting && !player.IsExhausted && player.CurrentStamina >= max - 0.001f;
                group.alpha = idle ? idleAlpha : 1f;
            }
        }
    }
}
```

```csharp
namespace Game.UI

    /// Fuse progress (TGD sections 33-37). Reads ObjectiveManager directly; the objective -> exit
    /// link stays in SceneWiring where it already lives, because a HUD element must never be load
    /// bearing for gameplay.
    /// </summary>

    {
        [SerializeField] private ObjectiveManager objectives;
        [SerializeField] private Text label;

        [SerializeField, Tooltip("{0} = completed, {1} = required.")]
        private string format = "SİGORTA {0}/{1}";

        [SerializeField] private string allCompleteText = "ÇIKIŞ AÇILDI";

        [SerializeField] private Color normalColor = new Color(0.88f, 0.88f, 0.85f, 0.92f);
        [SerializeField] private Color flashColor = new Color(1f, 0.9f, 0.5f, 1f);
        [SerializeField] private float flashSeconds = 0.6f;

        private bool allComplete;
        private float flashTimer;

        public void Bind(ObjectiveManager objectiveManager) => objectives = objectiveManager;

        private void Awake()
        {
            if (objectives == null || label == null)
            {
                // Expected in MainGame until the fuse system lands there — the widget stands down
                // instead of throwing every frame (spec section 6.2).
                Debug.LogWarning($"[HUD] {name}: ObjectiveManager/label not assigned — fuse counter disabled.", this);
                if (label != null) label.enabled = false;
                enabled = false;
                return;
            }

            label.color = normalColor;
        }

        private void OnEnable()
        {
            if (objectives == null) return;
            objectives.OnAnyFuseCompleted += HandleFuseCompleted;
            objectives.OnAllComplete += HandleAllComplete;
            Refresh();
        }

        private void OnDisable()
        {
            if (objectives == null) return;
            objectives.OnAnyFuseCompleted -= HandleFuseCompleted;
            objectives.OnAllComplete -= HandleAllComplete;
        }

        private void HandleFuseCompleted() => flashTimer = flashSeconds;

        private void HandleAllComplete() => allComplete = true;

        private void Update()
        {
            if (flashTimer > 0f)
            {
                flashTimer -= Time.deltaTime;
                float t = flashSeconds > 0f ? Mathf.Clamp01(flashTimer / flashSeconds) : 0f;
                label.color = Color.Lerp(normalColor, flashColor, t);
            }
            else if (label.color != normalColor)
            {
                label.color = normalColor;
            }

            Refresh();
        }

        /// <summary>The single place this widget reads gameplay state (spec section 8).</summary>
        private void Refresh()
        {
            int required = objectives.RequiredCount > 0 ? objectives.RequiredCount : objectives.RegisteredCount;
            if (allComplete || (required > 0 && objectives.CompletedCount >= required))
            {
                label.enabled = true;
                label.text = allCompleteText;
                return;
            }

            // RequiredCount is only set once something calls SetRequiredCount. The fuse spawner does
            // not exist yet, so fall back to how many boxes have actually registered rather than
            // showing the player a meaningless "0/0".
            if (required <= 0)
            {
                label.enabled = false;
                return;
            }

            label.enabled = true;
            label.text = string.Format(format, objectives.CompletedCount, required);
        }
    }
```

```csharp
using System;
using Game.Core;
using UnityEngine;

namespace Game.UI
{
    /// <summary>
    /// Shows the HUD only during states where the player is actually playing. Hidden during the fuse
    /// minigame because FuseMiniGameController lays its own darkening overlay across the screen and a
    /// HUD floating on top of it collides with the panel visually.
    ///
    /// Drives CanvasGroup alpha, never SetActive: keeping the hierarchy active preserves continuous
    /// spring updates, matched event subscriptions, and the fade itself while the HUD is hidden.
    /// </summary>
    [DisallowMultipleComponent]
    public class HudVisibility : MonoBehaviour
    {
        [SerializeField] private GameFlowController gameFlow;
        [SerializeField] private CanvasGroup hudGroup;
        [SerializeField] private float fadeSeconds = 0.15f;

        [SerializeField, Tooltip("Game flow state type names during which the HUD is visible; compared against GameFlowController.CurrentStateName.")]
        private string[] visibleStates =
        {
            nameof(ExplorationState),
            nameof(FinalChaseState),
        };

        private float targetAlpha;

        public void Bind(GameFlowController flow, CanvasGroup group)
        {
            gameFlow = flow;
            hudGroup = group;
        }

        private void Awake()
        {
            if (gameFlow == null || hudGroup == null)
            {
                Debug.LogWarning($"[HUD] {name}: gameFlow/hudGroup not assigned — HUD visibility control disabled.", this);
                enabled = false;
            }
        }

        private void OnEnable()
        {
            if (gameFlow == null || hudGroup == null) return;
            gameFlow.OnStateChanged += HandleStateChanged;
            // GameFlowController enters Initialization in its own OnEnable, which may already have
            // fired before this subscription existed. Seed from the current state so the HUD never
            // waits for the next transition to find out whether it should be showing.
            HandleStateChanged(gameFlow.CurrentStateName);
            hudGroup.alpha = targetAlpha;
        }

        private void OnDisable()
        {
            if (gameFlow == null) return;
            gameFlow.OnStateChanged -= HandleStateChanged;
        }

        private void HandleStateChanged(string stateName)
        {
            targetAlpha = Array.IndexOf(visibleStates, stateName) >= 0 ? 1f : 0f;
        }

        private void Update()
        {
            hudGroup.alpha = fadeSeconds <= 0f
                ? targetAlpha
                : Mathf.MoveTowards(hudGroup.alpha, targetAlpha, Time.deltaTime / fadeSeconds);
        }
    }
}
```

```csharp
using Game.Core;
using Game.Gameplay.Interaction;
using Game.Gameplay.Objectives;
using Game.Gameplay.Player;
using Game.UI;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEngine;
using UnityEngine.UI;

namespace Game.Editor
{
    /// <summary>
    /// Builds the HUD hierarchy into the open scene (Tools > Gloomveil > UI > Build HUD).
    ///
    /// MainGame.unity is saved with binary serialization, so this layout cannot be authored or
    /// reviewed as text — a builder is the only way to keep it reproducible and diffable. Re-running
    /// deletes the previous HudCanvas and rebuilds from scratch, so tuning the constants below and
    /// rebuilding is the intended workflow.
    ///
    /// Missing gameplay sources are not an error: ObjectiveManager in particular does not exist in
    /// MainGame yet (the fuse system is being built separately), and its widget is designed to stand
    /// down quietly (spec section 6.2).
    /// </summary>
    public static class HudSceneBuilder
    {
        private const string RootName = "HudCanvas";
        private const float ReferenceWidth = 1920f;
        private const float ReferenceHeight = 1080f;

        private const float CornerMarginX = 48f;
        private const float CornerMarginY = 44f;
        private const float PromptBottomOffset = 190f;
        private const float CrosshairTickDistance = 10f;

        [MenuItem("Tools/Gloomveil/UI/Build HUD")]
        public static void BuildHud()
        {
            var existing = GameObject.Find(RootName);
            if (existing != null) Undo.DestroyObjectImmediate(existing);

            Font font = Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf");

            GameObject canvasObject = new GameObject(RootName,
                typeof(Canvas), typeof(CanvasScaler), typeof(CanvasGroup), typeof(HudCameraMotion),
                typeof(HudVisibility));

            var canvas = canvasObject.GetComponent<Canvas>();
            canvas.renderMode = RenderMode.ScreenSpaceOverlay;

            var scaler = canvasObject.GetComponent<CanvasScaler>();
            scaler.uiScaleMode = CanvasScaler.ScaleMode.ScaleWithScreenSize;
            scaler.referenceResolution = new Vector2(ReferenceWidth, ReferenceHeight);
            scaler.screenMatchMode = CanvasScaler.ScreenMatchMode.MatchWidthOrHeight;
            scaler.matchWidthOrHeight = 0.5f;

            // No GraphicRaycaster and no raycast blocking: the HUD is never clickable, and leaving
            // either on would let it swallow the fuse minigame's button clicks once that UI is in
            // this scene.
            var canvasGroup = canvasObject.GetComponent<CanvasGroup>();
            canvasGroup.interactable = false;
            canvasGroup.blocksRaycasts = false;

            var motion = canvasObject.GetComponent<HudCameraMotion>();
            Camera playerCamera = Camera.main;
            if (playerCamera != null) motion.Bind(playerCamera.transform);
            else Debug.LogWarning("[HUD Builder] No MainCamera found — HUD sway will rest until HudCameraMotion is bound.");

            var flow = Object.FindFirstObjectByType<GameFlowController>();
            if (flow != null) canvasObject.GetComponent<HudVisibility>().Bind(flow, canvasGroup);
            else Debug.LogWarning("[HUD Builder] No GameFlowController found — HUD visibility control will stay disabled.");

            RectTransform swayRoot = CreateFullScreenChild(canvasObject.transform, "SwayRoot");
            swayRoot.gameObject.AddComponent<HudRootSway>().Bind(motion);

            RectTransform fixedRoot = CreateFullScreenChild(canvasObject.transform, "FixedRoot");

            BuildObjective(swayRoot, motion, font);
            BuildStamina(swayRoot, motion);
            BuildFlashlight(swayRoot, motion, font);
            BuildPrompt(swayRoot, motion, font);
            BuildCrosshair(fixedRoot, motion);

            Undo.RegisterCreatedObjectUndo(canvasObject, "Build HUD");
            EditorSceneManager.MarkSceneDirty(canvasObject.scene);
            Selection.activeGameObject = canvasObject;
            Debug.Log($"[HUD Builder] Built '{RootName}' in scene '{canvasObject.scene.name}'. Save the scene to keep it.");
        }

            rect.anchorMin = Vector2.zero;
            rect.anchorMax = Vector2.one;
            rect.offsetMin = Vector2.zero;
            rect.offsetMax = Vector2.zero;
            return rect;

            rect.anchorMin = anchor;
            rect.anchorMax = anchor;
            rect.pivot = pivot;
            rect.anchoredPosition = anchoredPosition;

            text.fontSize = fontSize;
            text.alignment = alignment;

            Text label = CreateText(rect, "Label", font, 22, TextAnchor.MiddleCenter);
            label.text = string.Empty;

            var widget = rect.gameObject.AddComponent<InteractionPromptWidget>();
            var interaction = Object.FindFirstObjectByType<PlayerInteraction>();
            if (interaction != null) widget.Bind(interaction);
            else Debug.LogWarning("[HUD Builder] No PlayerInteraction found — the interaction prompt will stand down.");

            AssignSerialized(widget, "label", label);
            AssignSerialized(widget, "group", group);
        }

        private static void BuildCrosshair(RectTransform parent, HudCameraMotion motion)
        {
            var rect = CreateChild(parent, "CrosshairWidget", new Vector2(0.5f, 0.5f),
                new Vector2(0.5f, 0.5f), Vector2.zero, new Vector2(64f, 64f));

            var group = rect.gameObject.AddComponent<CanvasGroup>();
            group.interactable = false;
            group.blocksRaycasts = false;

            Color color = Color.white;
            Image dot = CreateImage(rect, "Dot", new Vector2(0.5f, 0.5f), new Vector2(0.5f, 0.5f),
                Vector2.zero, new Vector2(2f, 2f), color);

            var ticks = new RectTransform[4];
            var graphics = new Graphic[5];
            graphics[0] = dot;

            Vector2[] directions = { Vector2.up, Vector2.down, Vector2.left, Vector2.right };
            string[] names = { "TickUp", "TickDown", "TickLeft", "TickRight" };
            for (int i = 0; i < 4; i++)
            {
                bool vertical = i < 2;
                Vector2 size = vertical ? new Vector2(2f, 7f) : new Vector2(7f, 2f);
                Image tick = CreateImage(rect, names[i], new Vector2(0.5f, 0.5f), new Vector2(0.5f, 0.5f),
                    directions[i] * CrosshairTickDistance, size, color);
                ticks[i] = tick.rectTransform;
                graphics[i + 1] = tick;
            }

            var pulse = rect.gameObject.AddComponent<CrosshairPulse>();
            pulse.Bind(motion);
            AssignSerialized(pulse, "ticks", ticks);
            AssignSerialized(pulse, "group", group);

            var widget = rect.gameObject.AddComponent<CrosshairWidget>();
            var interaction = Object.FindFirstObjectByType<PlayerInteraction>();
            if (interaction != null) widget.Bind(interaction);
            AssignSerialized(widget, "parts", graphics);
        }

        /// <summary>
        /// Writes a private [SerializeField] through SerializedObject. Used only for the pure-view
        /// references (labels, images, groups) that a widget owns inside its own hierarchy — adding a
        /// public Bind overload for each of those would widen the runtime API purely to serve an
        /// editor tool.
        /// </summary>
        private static void AssignSerialized(Object target, string fieldName, object value)
        {
            var serialized = new SerializedObject(target);
            SerializedProperty property = serialized.FindProperty(fieldName);
            if (property == null)
            {
                Debug.LogError($"[HUD Builder] {target.GetType().Name} has no serialized field '{fieldName}'.");
                return;
            }

            switch (value)
            {
                case Object unityObject:
                    property.objectReferenceValue = unityObject;
                    break;
                case Vector2 vector:
                    property.vector2Value = vector;
                    break;
                case Object[] array:
                    property.arraySize = array.Length;
                    for (int i = 0; i < array.Length; i++)
                    {
                        property.GetArrayElementAtIndex(i).objectReferenceValue = array[i];
                    }
                    break;
                default:
                    Debug.LogError($"[HUD Builder] Unsupported value type for '{fieldName}'.");
                    return;
            }

            serialized.ApplyModifiedPropertiesWithoutUndo();
        }
    }
}
```

- [ ] **Step 2: Point them at the tuning fields**

All live-tunable in Play Mode:

| Component | Object | Fields |
|---|---|---|
| `HudCameraMotion` | `HudCanvas` | `smoothing`, `maxTrackedRate`, `teleportThresholdDegrees` |
| `HudRootSway` | `HudCanvas/SwayRoot` | `pixelsPerDegreePerSecond`, `maxOffsetPixels`, `degreesPerDegreePerSecond`, `maxRotationDegrees`, `stiffness`, `damping` |

Feel recipes:
- More corner fan-out → raise `HudRootSway.degreesPerDegreePerSecond` and `maxRotationDegrees`

- Looser, floatier → lower `stiffness` and `damping` together; snappier → raise both

**Play Mode Inspector edits are discarded on exit.** Once a value feels right, note it, stop Play, set it again, and save the scene.

## Notes for the implementer

- **Do not** add a `GraphicRaycaster` to `HudCanvas`, and do not set `blocksRaycasts = true` on its `CanvasGroup`. The fuse minigame's buttons live on a separate canvas and the HUD sits over the whole screen.
- **Do not** move `CrosshairWidget` under `SwayRoot` or add `HudSway` to it, however tempting the visual consistency. See spec 2.1 and 9.
- `ObjectiveWidget` staying hidden and warning once in `MainGame` is the designed behaviour until that scene gains an `ObjectiveManager`, not a bug to chase.
- The Turkish strings (`SİGORTA {0}/{1}`, `ÇIKIŞ AÇILDI`) are serialized fields, not hardcoded — they can be changed in the Inspector without touching code.
- Flashlight battery is deliberately absent but explicitly deferred, not rejected (spec section 1). If it lands later, it is a fill bar added to `FlashlightWidget` — no change to the hierarchy, motion model, or assembly layout.
